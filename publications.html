CVPR 2026 · Co-author

Quantum-Gated Task-interaction Knowledge Distillation for Pre-trained Model-based Class-Incremental Learning

Continual Learning Quantum Computing Knowledge Distillation
Paper Code

Key Innovations

  • Quantum-Gated Task Modulation (QGTM): introduces parameterized quantum circuits into class-incremental learning for the first time, encoding sample features and task embeddings into Hilbert space via quantum superposition and interference, and dynamically quantifying sample-to-task relevance through fidelity measurement — breaking the expressiveness ceiling of classical similarity metrics.
  • Correlation-guided Task-Interaction Knowledge Distillation (TIKD): leverages the correlation coefficients from quantum gating as adaptive weights, selectively transferring knowledge from highly correlated historical adapters while suppressing interference from weakly correlated tasks, enabling precise inter-task knowledge transfer.
  • Unified routing for training and inference: a single quantum-gating module simultaneously drives cross-task knowledge distillation during training and adaptive adapter fusion during inference, keeping training objectives consistent with inference behavior and resolving the routing challenge under task-agnostic evaluation.

The first quantum-computing-based routing framework for class-incremental learning — achieves state-of-the-art performance on five benchmarks under the exemplar-free setting, opening a new technical path for task-interaction modeling.

ICASSP 2026 · Co-author

LDE Prompt: Layer-importance guided Dual Expandable Prompt Pool for Pre-trained Model-based Class-Incremental Learning

Continual Learning Prompt Tuning Vision-Language
Paper Code

Key Innovations

  • Information-gain-driven adaptive layer selection: quantify each transformer layer's importance via mutual information (information gain); a forward pass before training each new task automatically picks the most informative layers for prompt injection, replacing the coarse strategies of hand-tuned presets or full-layer injection.
  • Dual expandable prompt pool architecture: a frozen Global Pool stores all historical task knowledge while a Training Pool holds only the current task's trainable prompts — jointly resolving the conflict between overwriting old prompts and using a fixed-capacity pool.
  • Dynamic pool expansion with cross-task sharing: similar prompts are retrieved from the Global Pool and expanded into the Training Pool during training, then archived back to the Global Pool afterward — growing pool capacity dynamically while similarity matching promotes prompt reuse across tasks and eliminates redundant learning.

The first prompt-pool framework integrating information-gain-driven adaptive layer selection with dynamic dual-pool expansion — comprehensively surpassing prior methods on three benchmarks.
