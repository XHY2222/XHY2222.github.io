# 肖慧宇 · Xiao Huiyu

个人主页源码，部署在 GitHub Pages：<https://xhy2222.github.io>

## 本地预览

直接双击 `index.html` 用浏览器打开就行，无需任何构建步骤。

## 更新流程

```bash
# 1. 在本地改文件（index.html / style.css / script.js）
# 2. 提交并推送
git add .
git commit -m "更新内容"
git push

# 几十秒后 https://xhy2222.github.io 自动生效
```

## 在其他电脑上同步

```bash
git pull
```

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 页面结构和内容 |
| `style.css` | 样式（含深色模式、响应式） |
| `script.js` | 主题切换 + 滚动动画 |
